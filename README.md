# 💰 Budget Tracker

A lightweight, modern, and responsive personal finance management application built with vanilla web technologies. This application helps users track their incomes and expenses, monitor their live total balance, and persist data locally.

🔗 **Live Demo:** [https://elitasadnan.github.io/Budget-Tracker/](https://elitasadnan.github.io/Budget-Tracker/)

---

## ✨ Features

* **Real-time Balance Calculation:** Automatically updates total income, total expense, and net balance upon adding or deleting items.
* **Local Storage Persistence:** Keeps financial records stored safely in the browser so data isn't lost on page reload.
* **Input Validation & Safety:** Prevents empty descriptions or non-positive amount entries.
* **Empty State Display:** Displays a clean placeholder message when no transactions are listed.
* **Fully Responsive UI:** Optimized layout using CSS Grid and Flexbox for seamless use across mobile and desktop devices.
* **Event Delegation:** Optimized DOM event management for handling dynamic element deletions efficiently.

---

## 🛠️ Tech Stack

* **HTML5:** Semantic markup structure (`main`, `section`, `article`, etc.)
* **CSS3:** Custom variables (`:root`), Flexbox, Grid, and Media Queries
* **JavaScript (ES6+):** Dynamic DOM Manipulation, Array Methods (`filter`, `reduce`), Event Handling, and Web Storage API (`localStorage`)
